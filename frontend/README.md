# recipe-generator-frontend

> **Personal vibe-coding playground — work in progress.** This is a personal project I'm building for fun. Code quality and features are evolving; expect rough edges.

Expo / React Native mobile app for the Recipe Generator project. Works on iOS, Android, and web.

## Features

### Recipe Generation

| Mode | How it works |
|------|-------------|
| **Text** | Type a description, dish name, or any free-form request |
| **URL** | Paste a recipe page link; the backend scrapes and converts it |
| **Image** | Pick from the camera roll, take a photo, or paste from clipboard (web) |
| **Voice** | Record audio (UI only — backend voice endpoint not yet implemented) |

While typing in text mode:
- **Inline AI suggestion** appears after a short pause; press Tab (web) or tap the ghost text to accept.
- **Dynamic preference chips** are generated by the LLM based on your input (e.g. "Spicy?", "Gluten-free?"). Answering them refines the generation prompt.

### Recipe View and Editing

After generation the recipe is displayed as structured sections (ingredients + steps) alongside a Markdown preview.

- **Per-item inline AI edit** — tap the edit icon on any ingredient or step, type a short instruction, and only that item is regenerated in-place. A diff highlight shows what changed.
- **Full reprompt** — use the "Refine" text box to request a broader change to the whole recipe.
- **Save** — saves the recipe to your account (requires sign-in). A "recently saved" confirmation appears.
- **Copy to clipboard** — copies the full recipe text.

### My Recipes

- Lists all saved recipes for the signed-in user.
- Tap a card to expand/collapse the recipe content.
- **Pull to refresh** reloads the list.
- **Delete** with confirmation dialog.
- Inline editing of saved recipes (name, content) via PATCH.

### Profile

- Displays name, email, and username from the OIDC token.
- Logout clears stored tokens and redirects to Generate.

### UI

- **Dark / light theme** toggle (defaults to dark).
- Responsive web layout: single-column on mobile, wider card layout above 720 px.
- Escape key navigates back on web (via `useEscapeBack` hook).

## Getting Started

### Prerequisites

- Node.js 18+
- Expo CLI (`npm install -g expo-cli` or use `npx expo`)
- Running backend at `http://localhost:8080/api/v1` (see `recipe-generator/`)
- Keycloak instance at `https://sso.ili16.de` with realm `recipe-generator` and client `frontend`

### Install and run

```bash
cd recipe-generator-frontend/recipe-generator-mobile
npm install
npm start          # opens Expo dev menu
npm run ios        # iOS simulator
npm run android    # Android emulator / device
npm run web        # browser at localhost:8081
```

### Configuration

All runtime config lives in [`src/constants/index.ts`](recipe-generator-mobile/src/constants/index.ts):

```ts
// Point to your backend (use LAN IP for physical devices)
export const API_BASE_URL = __DEV__
  ? 'http://192.168.x.x:8080/api/v1'
  : 'https://your-production-api.com/api/v1';
```

Key values to set for your environment:

| Constant | Purpose |
|----------|---------|
| `API_BASE_URL` | Backend REST API base |
| `KEYCLOAK_CONFIG.url` | Keycloak server URL |
| `KEYCLOAK_CONFIG.realm` | Keycloak realm |
| `KEYCLOAK_CONFIG.clientId` | OIDC client ID |
| `KEYCLOAK_CONFIG.redirectUri` | Deep-link redirect after login |

> For real devices, `localhost` does not resolve to your dev machine. Use the LAN IP instead.

## Authentication

Auth uses **Keycloak OIDC with Authorization Code + PKCE** via `expo-auth-session`.

- Tokens (access, refresh, expiry, profile) are stored in `AsyncStorage`.
- Every Axios request attaches the bearer token if one is available.
- On a `401` response the interceptor silently refreshes and retries once.
- Generation works without a token; save/list/update/delete require one.

## Backend API Summary

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | `/generate` | optional | Generate recipe (multipart) |
| POST | `/update-recipe` | required | AI reprompt on existing recipe |
| PATCH | `/update-recipe` | required | Persist manual edits |
| GET | `/get-recipes` | required | List user recipes |
| POST | `/add-recipe` | required | Save new recipe |
| DELETE | `/delete-recipe/:id` | required | Delete recipe |
| POST | `/suggest` | none | Inline text suggestion |
| POST | `/suggest-prefs` | none | Dynamic preference questions |
| POST | `/update-item` | none | Per-item AI rewrite |

## Known Limitations

- **Voice generation** — recording UI works but `apiService.generateByVoice` throws immediately; the backend does not support it.
- **Production API URL** — defaults to a placeholder; must be set before release.
- **No `.env` wiring** — config is in `constants/index.ts`, not `process.env`.
